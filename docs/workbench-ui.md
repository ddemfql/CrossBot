# 分步工作台与资料分类

本次调整 UI 编排，复用现有账号、Case、生成和知识版本服务；没有更改数据库 schema 或 W3 审核规则。

## 导航

侧栏按模块折叠：Case 协作、W1 询盘回复、W2 商品文案、W3 交易单证、资料与知识、设置与权限。
「资料与知识」是一个大分类，展开后选择三个独立子页，不能将它们作为混合内容导入：

| 子页 | 内容 | 公共类型 |
| --- | --- | --- |
| 产品资料 | 产品名称、SKU、规格、材质、包装、有依据的声明 | ProductData / ResourceKind.PRODUCT |
| 知识库 | 业务说明、FAQ、平台规则、适用条件 | KnowledgeData / ResourceKind.KNOWLEDGE |
| 风险词库 | 词项、匹配方式、风险级别、替换建议 | ProhibitedTermData / ResourceKind.PROHIBITED_TERM |

W1/W2 使用「填写资料 → 生成与修订 → 复核与导出」；W2 沿用现有单次生成服务，可重新生成，不新增多轮修订契约。
步骤切换、页面切换保留 Case 输入与历史。进入导出前同时绑定当前 Case 的两份工作流记录，防止把另一 Case 的结果带入导出。
「复核与导出」只是人工核对与下载页面，不等于服务端审批通过，不自动发送客户、发布平台或关闭 Case。
W3 沿用原来的文件、人工复核、核验与导出控件。

## 真实、模拟与断网

- 默认模拟演示区：只显示标记 is_demo 的 Case；可载入样例、模拟客户、调用本地 Mock。
- 真实工作区：只显示非演示 Case；首次空白输入；在「设置与权限 → 模型服务」配置 API 并确认发送后才能生成。不显示案例载入、模拟客户或连接测试按钮。
- 新建 Case 随当前区域标记是否为演示 Case；现有 Case 内容不迁移、不删除。
- 断网保底测试：独立入口，无需 Case/Key，使用固定动物台灯样例测试 W1/W2；结果保留在独立会话键，不保存到业务 Case，不调用真实模型。
- 真实调用失败时仍显示失败，不自动回退为模拟结果。

## 管理员上传

管理员、已有资料编辑权限的产品岗位可上传草稿；其他岗位仅按原有权限查看。所有写入继续调用 KnowledgeService，并在服务端重新核权。

1. 选择正确子分类，下载该分类的 JSON 模板。
2. 填写后上传，预览内容；多条记录需选择本次保存的条目，一次保存一条，不承诺批量事务。
3. 填写资源标识、真实来源、适用市场/平台/产品范围和生效日期。
4. 保存草稿，保留原件 SHA-256 与版本。相同标识的新内容追加版本；相同内容拒绝重复保存；同一标识不能跨分类使用。
5. 提交审核，另一名有审核权限的成员审核后，管理员才能发布。本人不能自审。演示区上传自动使用 demo: 标识和 demo 来源，不能发布为正式资料。

产品与风险词库支持 UTF-8 JSON/CSV；知识库另支持 UTF-8 TXT/Markdown。最大 2 MB，最多 200 条候选记录。CSV 的 content 列是按分类模板填写的 JSON 对象。PDF/Word/图片识别未新增到此上传入口，原有 W3 文件功能保持原流程。

**接入边界：上传、审核、发布目前管理的是版本化资源。W1/W2 检索和风险扫描仍使用原有内置演示 JSON，尚不会自动读取这里上传的资源。** 本轮没有把未审核上传当作已确认产品事实，也没有宣称上传后 AI 已立即采用。

## 验证

`tests/test_workbench_ui.py` 使用临时合成数据库覆盖：一个父分类/三个子页、三类管理员上传、类别混入拦截、重复/版本/原件、无权限写入、真实/模拟隔离、跨步骤与页面状态、Key 仅留会话，以及断网结果不写入 Case。

本地视觉验收使用独立临时数据库与合成账号，不读取真实账号或客户内容；视觉验收入口不属于正式应用，不应提交到项目。
