# 工作台 UI

当前主入口只提供真实工作界面。W1 无需先选 Case；W2 与 W3 使用已授权 Case。

侧栏分为 Case 协作、W1 询盘回复、W2 商品文案、W3 交易单证、资料与知识、设置与权限。
资料与知识是一个父分类，展开后选择产品资料、知识库、风险词库三个独立页面。
无权限的岗位操作禁用，服务层仍重新核验权限。

W1 显示当前询盘对话；检索来源与订单候选字段默认折叠。生成失败保留客户消息，重试不会重复提交消息。
明确下单后显示“前往订单核对”，自动选择新 Case。订单草稿不表示已审核或已付款。
W2 保留生成与审核步骤，产品事实、规则来源和风险信息按需展开。
W3 接收 W1 原文快照，上传平台原始订单，机器结果经人工复核后参与确定性比对。

账号设置支持有效会话刷新恢复，API 配置按用户隔离；加密记住密钥是可选项。
模拟环境切换、案例一键载入和断网保底入口从主路由移除。
历史模拟版本恢复方式、工作流边界及数据表见 [真实工作流](real-workflow.md)。
