## 接入边界

- 链接登记只表示候选来源，不代表 CrossBot 已访问、抓取或验证页面，也不代表赛事要求必须接入。
- 不根据网站首页、导航标题或搜索摘要编造规则正文。每条候选知识必须对应可复查的原始页面，并保留标题、完整 URL、发布日期/生效日期、适用平台/市场及引用原文。
- 未确认日期、适用范围或页面版本时，标为未知并要求人工复核；不能据此输出“合规通过”或确定认证义务。
- 现有 V3 契约禁止 `external_reference` 来源直接发布为正式知识。此类内容当前只能作为草稿/审核参考；不得通过改标 `local` 绕过门禁。如团队决定让已核实的官方规则进入正式检索，应先由公共契约负责人明确来源类型与发布门禁，再在 B 分支按新契约实现。
- 不自动爬取或批量镜像网站。本登记不判断网站授权、抓取条款或具体规则的法律效力。

## 后续流程

1. 人工打开规则中心，选取与当前产品、目标市场或平台相关的具体规则页面。
2. 保存页面标题、URL、可见版本/日期、适用范围和必要的原文摘录，并由第二人核对来源与解释。
3. 在知识管理中建立 `external_reference` 草稿，记录来源和范围；当前发布门禁会阻止其作为正式知识发布。
4. 由团队确认公共契约是否需要新增可发布的官方来源类别，再决定是否实现正式检索接入。
