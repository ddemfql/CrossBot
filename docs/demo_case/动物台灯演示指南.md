# 动物造型台灯 W1/W2 固定演示

## 数据口径

`CASE-DE-ANIMAL-LAMP-001` 与 `DEMO-ANIMAL-LAMP-001` 是为现场稳定演示自编的虚构案例。供应商 `CrossBot Demo Lighting`、德国买家、订单号、价格、贸易条件、接口、功率、电池、周期、包装和重量均为演示设定，不关联任何真实供应商页面或真实商品。不可把数据表述为实物验证、实际报价、合同或认证证明。

产品主档在 `knowledge/animal_lamp_knowledge.json`，固定订单和操作脚本在 `animal_lamp_fixture.json`，可编辑的风险词库在 `knowledge/prohibited_terms.json`。版本统一为 `animal-lamp-demo-1`。现存 `CASE-DE-LAMP-001` 与本案例互不覆盖；旧案例继续服务历史记录。

## 固定订单及算术

- 500 件 × 18.50 EUR = 9,250.00 EUR 货品金额。
- 20 件/箱，共 25 箱。
- 单件净重 0.4 kg；每箱净重 8 kg、毛重 10 kg。
- 总净重 200 kg、总毛重 250 kg。
- EXW Hangzhou；运费、进口税费、付款条件与送达日期不包含或待确认。
- 演示生产周期为订单确认并收到约定款项后 25 个工作日，不包括运输时间。该周期是自编例子。

载入函数会校验金额、件/箱、单位净重、箱净重和总重量之间的算术。缺字段、JSON 错误、版本错配或任一计算不一致时拒绝载入。

## W1 操作

1. 导入“动物台灯固定演示案例”，切到对应 Case。
2. W1 点击“载入动物台灯固定案例（自编演示数据）”。
3. 用固定英文询盘生成首版；确认数字、EXW 和“不含运输费及进口税费”保留。
4. 依次提交 fixture 中两条修改意见。每版都重新跑词项和数值检查。
5. 展示待确认项：认证文件、证书号、EPR/WEEE/LUCID 注册、续航、付款和送达日期。

## W2 操作

1. 选择 Amazon 与 TikTok，点击动物台灯资料按钮。
2. 生成后检查产品事实、适用平台范围和风险提示。
3. 使用 fixture 的 `risk_sample` 验证认证、绝对保证、健康功效、电池续航和未提供数值均产生风险。
4. 使用 `safe_sample` 验证已给参数能正常通过本地词项提示；生成仍是草稿，需人工复核。
