## 可重复演示

1. 默认模拟模式，在 W1 载入资料，检查数量 500、Germany 与三档色温。
2. 展开“询盘意图与字段候选”，查看引用原文和字符位置；点击识别仍为候选，不自动确认字段。
3. 生成回复并做两轮修改。检查风险、待确认项和来源；不把回复当作放行。
4. 展开模拟客户练习，生成问题；只有点击填入询盘才改变表单，不自动发送消息。
5. 切 W2，载入同一案例，选择 Amazon/TikTok 后生成，核对所选平台与参数。
6. 需要真实调用时由用户本机设置并确认，每个识别/模拟/回复按钮分别调用模型、可能产生费用。助手离线测试不发真实请求。
