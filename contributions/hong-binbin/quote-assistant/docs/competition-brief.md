# AI+出海参赛资料与验收清单

整理日期：2026-10-26。依据：用户两批共 21 张截图及群公告；不是完整网页导出。截图编号与原图见 [来源索引](sources/screenshots/README.md)。下文“要求”是截图中的赛事要求；“建议”是助手的筹备建议。尚未选定具体产品或技术方案。

## 赛事与定位

- INTERCITY HACK · 杭甬温三城联动黑客松，宁波站，用户已选择 AI+出海（AI+外贸/跨境）。
- 日期：2026-10-31（周六）至 2026-11-01（周日）。
- 场地：浙江省宁波市鄞州区甬江大道与翔海路交叉口东 200 米，鲲鹏馆。
- 1–4 人一队，允许单人；每个人与团队只能选择一个相同赛题。可跨校、跨公司，不能跨城市组队。全员分别报名，队长统一登记队伍；10 月 31 日 12:30 前确认队伍与队名。
- 开发阶段除晚上休息外须全程线下驻场；不能上午到场需提前联系组委会。
- 来源：[A03](sources/screenshots/A03.png)、[A04](sources/screenshots/A04.png)、[B04](sources/screenshots/B04.png)。

赛题聚焦三个痛点：询盘转化低（买家背景调查与跟进不足）、上品/出图/客服等重复劳动、跨岗位数据割裂。鼓励用 AI 打通“数据→知识→多角色工作流”，工具须便于外贸人员使用。评审关注真实业务适配、有效数据与知识库、本地化且可执行的产出，以及稳定的数据连接。[A01](sources/screenshots/A01.png)

## 基础验收：先满足，再讨论加分

下表均未标记完成；现在只是整理要求，没有构建参赛作品。证据列是建议的验收方法。

| 编号 | 截图要求 | 建议保留的证据 |
|---|---|---|
| R01 | 自选核心业务场景，说明目标用户、目标平台/市场、问题、价值、触发方式、逻辑、输出与涉及岗位 | 一页场景说明与真实业务样例 |
| R02 | 创建 AI 应用/智能体，配置角色、任务、交互方式、市场知识及必要能力；平台不限 | 配置导出或截图、可运行工程 |
| R03 | 支持中文或目标语言输入；本地化产出覆盖至少 **2 种目标语言，或 2 类角色/场景** | 两份目标不同的业务输出；不把“或”改成“且” |
| R04 | 完成至少 **两轮对话式迭代** | 原始输入、反馈、修订后的连续交互记录 |
| R05 | 适配至少 **2 个目标平台或场景**，体现商务语境与文化适配，不能只做直译 | 平台/场景差异及对应输出对照 |
| R06 | 至少 **两类校验**：合规、平台规则、文化敏感、合同条款中选择 | 可追溯规则、命中项与依据 |
| R07 | 至少 **两种反馈方式**：文本批注、风险标记、可视化对比、语音等 | 两种可见反馈的运行结果 |
| R08 | 至少一项工作流、场景、知识库等能力配置，并完成一次实际调用 | 输入、调用、返回结果记录 |
| R09 | 现场展示稳定可重复的“理解→生成→校验→反馈”端到端交互，包含至少 **两个相关工作流** | 可复现的演示步骤与调用记录 |
| R10 | 说明用户输入、业务/市场数据、生成结果、校验结果的传递、调用关系、返回值与异常处理 | 架构/数据流说明及失败恢复演示 |

来源：[A01](sources/screenshots/A01.png)、[A02](sources/screenshots/A02.png)。R03 与 R05 是不同要求，应分别核对；配置一项能力也不替代展示两个相关工作流。

示例产出可为话术、报价单、诊断报告、Listing、商品图。平台示例包括阿里国际站 RFQ、Amazon Listing、TikTok 内容，但并不强制选用这些平台。批量生成是鼓励项，多岗位输出在演示条款中是可选项，不能误列为额外硬门槛。

## 规则、资源与现场准备

### 作品与数据

- 禁止拿过往黑客松项目或成熟项目参赛；作品须原创。开源模型/API 可以使用，但须遵守许可、企业数据保密与赛事诚信规则。[A10](sources/screenshots/A10.png)、[B04 Q19–20](sources/screenshots/B04.png)
- 自取数据需合法授权；主办方提供的参考包括公开平台规则、合规/敏感词知识库和可能的模型/翻译/素材 API 额度，均不是强制指定技术栈。[A01](sources/screenshots/A01.png)
- 企业业务数据仅限赛事内使用，遵守保密约定，赛后按约删除或归还。[B03 Q23](sources/screenshots/B03.png)
- 手册称作品由参赛者保留所有权、企业享优先对接/使用权；具体以参赛协议为准。截图不能代替尚未提供的协议条款，也不代表用户已签署或授权。[B03 Q22](sources/screenshots/B03.png)
