# 数据来源与知识依据说明

项目：询盘与报价小助手｜参赛者：洪彬斌｜核对日期：2026-10-30

本原型使用自建模拟业务资料、公开规则的有限摘要和用户实际调用模型生成的草稿。当前没有真实客户、供应商、成交或平台后台数据；没有抓取真实 RFQ，也没有购买商业数据库。

## 知识依据如何构建与调用

当前“知识库”是**本地结构化商品目录与规则文件**，没有向量数据库、嵌入模型、检索增强服务或外部知识库平台。

1. `catalog.py` 读取并校验商品JSON，`quotation.py` 按数量取阶梯价格，用Decimal计算金额。
2. 规则模块根据付款文本、场景、买家材质与商品材质产生检查结果；规则JSON保存版本、来源、查阅日期和适用范围。
3. 用户点击生成时，当前业务资料、程序计算金额、付款检查与RFQ报告进入模型请求；修订请求另附上一版业务资料和变化。
4. 模型输出英文客户回复与中文内部清单；C03在生成后筛查英文表述。成功版本保存草稿、输入、原始修改要求与各报告，供对比和导出。

没有实时查询阿里后台，也不会在运行时自动更新公开规则。更改本地规则后需重新验证；旧版本保存当时报告，不回写历史。

## 数据处理与展示约定

- 仅在用户点击理解／生成时向DeepSeek官方端点发送相关业务资料；API Key用于请求认证，不写入项目文档、导出或记忆。
- 本地检查、金额计算、下载和固定备份恢复不调用模型。历史保存在会话，用户主动下载才能长期保存。
- 当前生成结果保留模拟标识，不宣称真实成交、客户认可、收益增长或完整合规通过。
- 后续如接入真实商品、联系人或询盘，应先补充来源、使用授权和必要字段范围，再决定是否允许发送给外部模型；当前资料不能证明已经取得这些授权。

本轮未改变原始业务JSON、规则文件或演示证据。文件快照校验值见 [data-source-manifest.json](verification/data-source-manifest.json)。
