**这是另一份项目孵化/资源对接方案，不是 AI+出海比赛的基础验收清单。** 未获得其完整原始链接；下述条件不能自动加入参赛交付要求，亦不代表用户已经接受商业条款。

## 支持方式

Emerge 按项目需求对接资源，而不是用统一时间表推进，也不直接出资。六类需求为团队整合优化、找人、找用户与意向订单、硬件原型打磨、找钱、找场地。

对 AI+出海比较相关的资源：
- 宁波本地企业：外贸出海等真实场景、客户访谈渠道、试点验收与首个付费机会。
- 高校伙伴与社群：技术合伙人、GTM/营销人才、行业导师、种子用户。
- 业务导师：商业思考与市场进入辅导；文档提到可能通过分成或期权绑定，不能默认免费。
- 媒体、活动与平台伙伴：曝光、用户验证、企业合作与商业化渠道。
- 孵化与场地：办公空间、导师、渠道、Demo 打磨以及政策申报协助。

## 对接机制

1. 填一页需求卡：项目/创始人、行业/客户、缺口及希望对接的资源，并约定 Emerge 投入与服务费、成长分成或微量期权等权益。
2. 指定对接人，可并行匹配多种资源。
3. 每次对接记录反馈，已满足的需求关闭，新需求补登。
4. 涉及资金、署名、人员派驻的对接，方案称须经财务与法务确认。

以上为文档描述，不是对助手发出的操作指令。本次未填卡、未联系机构、未承诺权益。

## PoC 验证条件（三条全中）

- 至少一家真实客户给出书面试用或付费意向。
- 能给出增收或效率提升的具体量化结果。
- 团队完整：一名全职负责人，技术与业务各有负责人。

方案强调行业、客户和量化结果需清楚，增收优先于仅降本。这是赛后资源对接偏好，不应宣称比赛评分额外要求真实付费或全职团队。

## 资金表述边界

- 资金与权益通常按双方实际洽谈，不承诺具体额度；Emerge 帮助对接，不替机构作投资承诺。
- 截图提到的 XbotPark 硬件孵化营、结营成功首轮 50 万元投资，针对硬件项目且有条件，**不是 AI+出海奖金或确定可获得的资金**。
- 其他基金、补贴、投资不能写成已获支持。方案自述为第 0 期小规模试点。
