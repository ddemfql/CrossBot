# 运行与演示说明

适用版本：2026-10-30，本机 Streamlit 三页签原型。项目根目录是包含 `start-local.cmd` 的文件夹。既有演示已经通过，无须为阅读本说明重复调用模型。

## 1. 在参赛电脑上重新打开

1. 打开项目文件夹，双击 `start-local.cmd`。
2. 保留启动窗口，浏览器打开 <http://127.0.0.1:8501/>。
3. 应看到「询盘与报价小助手」及「1 填写需求」「2 检查并生成」「3 修订与下载」。

只关闭浏览器后，可以先重新访问地址；若不能连接，再启动程序。若提示端口已被占用，先访问原地址核对是不是本项目，不反复启动或结束不明进程。

停止前先下载备份，再在自己的启动窗口按 Ctrl+C。关闭启动窗口也会结束服务。重新启动后需自行重新输入密钥；历史可能为空。

PowerShell 备用启动命令（在项目根目录运行）：

```powershell
& '.\.venv\Scripts\python.exe' -m streamlit run local_lab/app.py --server.address 127.0.0.1 --server.port 8501 --server.headless true --browser.gatherUsageStats false
```

## 2. 环境缺失或换电脑

已验证环境：Windows、Python 3.12.14、Streamlit 1.66.1、Pydantic 2.14.1。不要求 GPU 或 Docker。现有电脑已安装，不必重建；另一台电脑尚未实测。

新电脑需真实的 Python 3.12 解释器；将下列占位路径替换为其实际位置，在项目根目录执行：

```powershell
& 'C:\path\to\python.exe' -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip --isolated install --index-url https://pypi.org/simple -r requirements-lock.txt
& '.\.venv\Scripts\python.exe' -m pip check
& '.\.venv\Scripts\python.exe' -c "import sys, streamlit, pydantic; print(sys.version); print(streamlit.__version__, pydantic.__version__)"
```

安装依赖需要网络。不要直接把另一台电脑的 `.venv` 当作可移植环境；它依赖基础解释器路径。当前参赛电脑 PATH 中的 `python` 曾是 Windows 商店占位程序，应使用项目 `.venv` 中的解释器。

至少保留项目中的 `local_lab/`、`planning/fixtures/`、启动脚本和依赖文件。若要使用恢复按钮，还必须保留 `docs/verification/rfq-live-history.json` 与 `demo-round1-history.json` 的原始字节，不能重新格式化；程序校验其 SHA256。最新 V3 完整备份另见 `demo-two-rounds-history.json`。

## 3. 模型配置与费用

在「2 检查并生成」展开「模型设置 · DeepSeek 密钥」，自行填入现有 DeepSeek 官方 API Key。不要将密钥贴到聊天、说明文档或截图中。可使用「清除密钥」移除会话中的值。

| 设置 | 当前实现 |
|---|---|
| 服务地址 | `https://api.deepseek.com/chat/completions` |
| 模型 | `deepseek-flash`，代码固定 |
| 理解修改 | 「让 AI 理解修改」，最多输出700 tokens |
| 生成草稿 | 「生成英文回复与中文清单」，最多输出1800 tokens |
| 调用行为 | 非流式；超时设置60秒；无自动重试 |
| 本地操作 | 查价、算金额、规则检查、预览、下载与恢复不调用模型 |

初始生成一次，加两轮各一次理解和生成，正常成功路径共五次模型请求；手动重试会增加请求。输入 token 与输出 token 都可能产生费用，上限不是总费用保证。当前业务资料会发送至 DeepSeek；生成前可展开「查看将发送给模型的资料（不含密钥）」核对。

## 4. 首次报价演示

以下从空历史的新会话开始。如果当前已有重要记录，先下载；不要为重做演示随意刷新现有会话。历史不空时新版本会继续编号，不一定是 V1。

在「1 填写需求」输入：

| 字段 | 值 |
|---|---|
| 选择商品 | BAG-001 · 洪彬斌的练习布袋 |
| 采购数量 | 500，按 Enter 确认 |
| 付款条件 | 拟议条款，50% 预付款，50% 发货前支付，待双方确认 |
| 本次业务场景 | 阿里国际站 RFQ（模拟场景） |
| 买家要求的材质 | 涤纶 |

核对：单价1.20 USD、货品金额600.00 USD。在「2 检查并生成」应看到付款比例合计100%、买家涤纶与商品棉布不同的提示。比例通过仅代表算术一致。

自行配置密钥并点击「生成英文回复与中文清单」。成功后到「3 修订与下载」，展开「查看 V1 的两份草稿」，确认：英文明确材质差异并询问替代品，中英文数量／金额一致，付款仍待双方确认，没有编造运费、认证或承诺。AI 措辞可能不同，以事实核对为准。

## 5. 两轮对话修订

每轮都在「3 修订与下载」的「本轮修改要求」输入，再按顺序操作：

1. 点击「让 AI 理解修改」。
2. 核对变化表。
3. 点击「应用已核对的修改」。此时只更新输入，还没有新草稿。
4. 回「2 检查并生成」，核对新金额，点击「生成英文回复与中文清单」。
5. 回第三栏，检查新版本的原始修改要求、差异、两份草稿，再下载。

第一轮：

> 数量改成1000个，付款条件不变。

预期数量1000、单价1.05 USD、货品金额1050.00 USD，付款仍50%/50%。

第二轮：

> 付款条件改为：拟议条款，30%预付款，70%发货前支付，待双方确认。数量保持1000个。

预期数量、单价和货品金额不变，仅付款变为30%/70%，仍待双方确认；RFQ 材质差异保留。变化表只显示变化字段，未显示单价并不代表单价丢失，可回第一栏／第二栏核对完整金额。

已核实的三版结果见 [完整演示记录](verification/demo-two-rounds-review.md)。这两轮支持数量和付款，不支持通过对话修改材质、运费或其他字段。

## 6. 下载与恢复

所有版本下载位于「3 修订与下载」→「查看版本与下载」。

- 「下载所选版本（TXT）」：当前选中版本的草稿及报告。
- 「下载全部版本记录（JSON）」：当前会话全部版本，应在每次成功生成后保存。
- 第二栏的「下载当前 RFQ 预检（JSON）」只有材质预检，不能代替全部版本备份。

浏览器可能将重复下载自动命名为带 `(1)`、`(2)` 的文件；以实际下载位置和内容为准。保存新文件后再考虑清理旧文件，不覆盖唯一备份。

| 页面入口 | 恢复内容 | 限制 |
|---|---|---|
| 「恢复已归档的 RFQ V1」 | 500个、600 USD、50%/50%的原V1 | 只允许空历史且无草稿的会话 |
| 「恢复正式演示进度（第一轮 V1/V2）」→「恢复第一轮 V1/V2（替换当前会话）」 | 原V1/V2，当前1000个、1050 USD、50%/50% | 替换当前输入与历史；操作前先下载当前记录 |

恢复第一轮时，被替换历史暂存在会话，可用「下载恢复前的历史（JSON）」保存；这不是磁盘自动备份，仍可能随会话丢失。恢复不调用模型、不改密钥，但新会话通常需要自行重新输入密钥。

**现有两个恢复按钮都不包含最新 V3。** V3 已保存在项目 `docs/verification/demo-two-rounds-history.json`，可直接用文本编辑器查看，尚不能在页面任意上传导入。需要讲解已有结果时可展示归档并说明它是此前真实调用的导出，不冒充现场新生成。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 网页无法连接 | 查看自己的启动窗口是否还在；从项目根目录启动，再访问8501。 |
| 提示 Python 环境不存在 | 按第2节重建；不要用商店占位解释器。 |
| 商品文件错误／找不到 | 检查 `planning/fixtures/products.json`；恢复正确JSON后在第一栏「商品目录与数据来源」重新读取。 |
| 生成按钮不可用 | 检查商品、最低订购数量和付款比例错误；先修正输入。 |
| API Key 提示或401 | 在第二栏重新输入有效的官方密钥；不要把密钥发给他人排障。 |
| 402余额不足／429频繁 | 自行检查账户额度或稍后手动重试；程序不自动重试。 |
| 网络超时／输出格式不完整 | 本次不新增版本；保留已有历史，检查网络后决定是否手动重试。 |
| 修改已应用但还是旧草稿 | 还需回第二栏生成新版；查看历史时留意版本号和“历史输入”提示。 |
| 刷新后历史为空 | 按第6节选择固定归档恢复；未下载记录不能保证找回。 |
| 恢复提示备份不一致 | 保留现有备份，检查对应归档是否被修改；不要修改SHA校验值绕过检查。 |
| 更新代码后出现字段不存在 | 如能操作先下载，然后在自己的启动窗口Ctrl+C，重新启动并刷新；刷新网页不保证重载所有Python模块。 |

没有网络时仍可计算、检查、查看固定备份；无法执行新的 AI 理解或生成。现场可用归档讲解已验证结果，并明确网络状态。

## 8. 现场准备检查

- 页面可打开，BAG-001的500和1000数量分别显示600与1050 USD。
- 自己确认模型账户与网络可用；密钥不进入投屏截图。
- 保留已下载的三版JSON及需要展示的TXT，能找到它们的位置。
- 讲清“AI理解与表达、代码查价计算、人工确认”，以及金额不含运费等费用。
- 结束前下载、清除密钥，再关闭自己的服务窗口。
