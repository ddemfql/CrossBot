# 规划用模拟数据

日期：2026-10-27。用户同意使用公开资料与明确标注的模拟案例；具体产品方向仍是助手推荐，尚未明确确认。

- products.json：5 个原创虚构布袋 SKU；价格、MOQ、交期完全是测试设定。
- cases.json：12 个模拟询盘/修订用例，包含期待触发的规则和确定性金额。规则说明见 [选型方案](../../docs/product-direction.md)。
- 所有用例均未接模型评测，没有通过率或性能结果。
- public source 与 synthetic data 必须分别标注；这里没有真实客户/供应商信息。
- required_flags 为至少应提示的风险，并非总风险清单；规则时效未确认的提示必须显示参考性质。
- 样例单价是货品价，不含运输税费；不能因为用户填 FOB 就把该金额标为完整 FOB 报价。
- 未提供商品证书、现货或真实运费证明。模型不得编造。
- 修改为真实业务资料时，先补充授权来源、实际价格有效期和字段依据。
