# 🤖 CrossBot: 外贸智能业务员与合规助手
> **黑客松参赛作品** | 赛道二：AI+出海 | Tag: `hackathon-final`

CrossBot 专为跨境出海场景设计，打通“理解 → 生成 → 校验 → 反馈”全链路闭环。不仅能生成多语言/多平台内容，更能通过本地知识库（RAG）与规则引擎强制拦截合规风险，拒绝模型幻觉。

## 🎯 赛题得分点映射

*   **双相关工作流**：`W1 询盘极速转化`（客服场景） + `W2 多平台Listing生成`（运营场景）。
*   **多语言/多角色/多平台**：支持中→英/德翻译；一键生成 Amazon（严谨）与 TikTok（网感）双风格文案。
*   **双重合规校验**：本地规则引擎拦截“违禁词” + RAG匹配目标国“CE/FDA”认证要求。
*   **多种反馈方式**：流式打字机输出 + UI 红色风险标红 + 明确修改建议。
*   **多轮对话式迭代**：支持在 Chat UI 中持续输入修改意见，实时重写文案并重新合规审计。

## ✨ 核心创新：双引擎闭环
传统的 AI 助手只管“说”，我们的底座兼顾“审”。
输入业务需求 -> RAG注入防幻觉 -> 大模型流式生成 -> 本地规则引擎合规拦截 -> 反馈风险。

## W3 交易单证工作台

当前工作台已简化为 **管理员 / 业务员** 两种角色。业务员可以独立新建交易、导入 ZIP、上传与分类文件、补充资料、人工确认并生成 Excel、下载原件或打包所选文件；管理员另外负责开通账号。旧单证、复核、物流、财务账号登录时归为业务员，历史记录保留。

日常只需：**选择交易 → 查看分类和缺失文件 → 补充已知资料 → 勾选人工确认 → 生成与导出**。主界面只有“文件分类与查看”和“生成与导出”两个页签；不再显示岗位交接、逐项审批、运输和收款流程。新建交易允许资料暂缺，所需文件可按本单调整，已配置的条件规则仍有效。

无需准备或选择模板，当前生成简单 XLSX 文件；缺失内容留空并提示，人工确认绑定当次输入、来源版本、确认人和输出哈希。导出不等于 Case 审批通过，不自动记账或登记物流事实。原件、历史生成版本和审计保留；外部签发的提单、证书和回执仅保存真实原件。自定义模板上传与 PDF 生成留待后续实现。

启动：`streamlit run app.py`，选择 W3。数据默认存放在 `~/.crossbot/w3/`，可通过 `CROSSBOT_W3_DATA` 指定目录。测试：`python -m unittest discover -s tests -v`。接口说明见 [docs/w3-contracts.md](docs/w3-contracts.md)。

启动后在侧边栏选择 **W3 交易单证工作台**，使用已有本地账号登录。管理员可看到工作区所有交易、原件、表单和岗位待办，并开通销售、单证、复核、物流及财务账号。数据默认保存在 `~/.crossbot/w3/`（原件与产物在 files/，不可变历史快照在 workspace.sqlite3），可通过 CROSSBOT_W3_DATA 指定目录。适用于单机工作区，尚无多租户隔离或企业统一登录。

按一笔订单依次查看 **全流程总览 → 订单与待办 → 文件与表单 → 复核与批准 → 运输与收款 → 历史记录**。全流程总览按询盘报价、订单确认、产品合规、生产验货、出运单据、运输申报、收款归档展示当前留存情况；有资料不表示实际阶段完成，目录中的“已发货/待收款”仅保留为未核验声明。

文件中心有 **32 类文件与表单位置**，分为我方准备及外部资料；其中 **18 类卖方填写模板**包括报价、PI、销售合同、订单确认、产品规格、包装内容、生产要求、内部验货、CI、PL、CI/PL合并表、订舱、运输指示、报关准备、ISF准备、付款通知、对账、合规声明。未知信息留空；可编辑结构化字段和明细、查看采集原文及工作表。卖方模板可导出空白/当前填写稿 HTML；正式生成服务在资料确认后保存带模板版本、输入快照、输出哈希的新草稿版本，PI/CI/PL 为 XLSX，其余为 HTML。外部提单、证书、银行回单、官方回执由真实主体提供，系统保存、分类及抄录，不冒充签发。

| 界面 | 导出内容 | 格式 |
| --- | --- | --- |
| 全流程总览 | 整单档案、全流程资料包、虚拟业务员整理记录 | HTML、ZIP、CSV |
| 文件与表单 | 全部结构化数据、按名称整理的原件和填写模板包 | JSON、ZIP |
| 原始文件与采集信息 | 选定原始文件及历史版本 | 保持原始 PDF/XLS/XLSX/DOCX/图片等格式 |
| 填写表单 | 空白卖方模板 | HTML |
| 生成版本 | 选定草稿版本 | XLSX 或 HTML |

整单 ZIP 含所有原件版本、32 类表单 JSON/CSV、18 类空白 HTML 模板及已有填写稿、订单档案、生成产物、整理记录。解压后打开“订单档案.html”可按流程浏览并点击原件。完整 JSON 保留机器候选、虚拟业务员建议、人工确认、来源表格、字段位置、批准和审计；每次重新生成均保存新版本，不覆盖原件。

管理员可直接导入 ZIP，也可用命令 `python scripts/import_trade_archive.py <资料包路径> --admin <已有管理员账号>`；导入会先备份数据库、校验安全路径、逐份保存原件，并对相同包去重。单文件最大 20 MB。托管与解析能力分别处理：支持保存 PDF、XLS/XLSX、DOCX、图片、TXT/CSV；采集受支持的原文、工作表和标签字段，扫描件可本地 OCR。无法识别的内容保留原件并留空，未知格式不等于不能保存。

虚拟业务员辅助抄录单独保存 assisted_value、来源位置与依据，机器 value 保留，人工 confirmed_value 独立。辅助填写不自动确认、批准、记账、登记发货或收款。真人复核结合确定性规则后才能批准；主数据、表单或来源版本变化会使当前草稿和批准失效。待办可按岗位流转并指派到真实账号。

运行测试：`python -m unittest discover -s tests -v`。公共契约与边界见 [docs/w3-contracts.md](docs/w3-contracts.md)。真实交易 ZIP、导出物和客户数据不进入代码仓库。
